# Excerguide 運動紀錄

以健康為取向、走黑黃色塊風格的簡潔運動紀錄小網頁，使用 GitHub Pages 部署（純 HTML / CSS / JS，無需建置）。

## 功能

- **內建常見運動類別**：跑步、健走、騎自行車、游泳、重量訓練、瑜伽、跳繩、籃球、羽球、登山健行、HIIT、伸展，以及「其他運動」。
- **新增紀錄**：點選類別即可設定
  1. 運動名稱（預設為類別名稱，可自由修改，例如「慢跑」）
  2. 運動時間（拉桿 5–180 分鐘），並依體重與 MET 值估算消耗熱量
  3. Note（記錄這次運動的狀況）
- **紀錄列表與統計**：今日 / 本週分鐘數、本週大卡、每週目標進度條；點選紀錄可編輯或刪除。
- **運動小常識**：每個類別都有小常識，新增紀錄時也會隨機顯示一則。
- **基本身體數據**：首次使用時輸入（性別、年齡、身高、體重、每週目標），可直接跳過使用預設值，之後可在「設定」修改，並顯示 BMI。

所有資料只儲存在瀏覽器的 localStorage，不會上傳。

## 部署到 GitHub Pages

Repository → **Settings → Pages** → Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)` → Save。
幾分鐘後即可在 `https://<使用者名稱>.github.io/Excerguide/` 開啟。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。
